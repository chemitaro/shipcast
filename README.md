# shipcast

日々の開発の成果から、外へ発信する価値のある話題を拾い、X・note・Redditなどへの投稿の下書きを作る道具です。SpecDockと連携する道具の1つです。

開発をAIエージェントで並列にすると、成果は増えます。一方で、それを外へ伝える作業は手で行うままです。shipcastは次のことを行います。

1. Git・SpecDock・登録した成果から、出来事（Event）を集めます。
2. 公開の方針で絞り込み、意味のある話題（Story）にまとめます。
3. 発信する価値で判定し、まだ出せない話題は持ち越します。
4. 媒体ごとの下書き（X・note・Reddit、日本語と英語）を作ります。

**外への投稿は、必ず人間が行います。** shipcastは下書きと確認の画面までを作り、自分では投稿しません。

## 状態

構想と仕様を作っている段階です。動くコードはまだありません。議論と決定は[`content/`](content/)にあります。

## 置き場の原則

- このrepositoryには汎用のエンジンだけを置きます。公開してよい内容に限ります。
- 個人の設定（対象のrepository、公開範囲、NGワード）と実行の状態（素材、下書き、投稿の履歴）は、このrepositoryの外に置きます。
