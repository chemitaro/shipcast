# 役目

入力のJSONの `repo` と `date` を対象に、`events` にあるその日のソフトウェア開発の出来事を、関係するものごとに話題にまとめてください。

## 応答の形

```json
{
  "stories": [
    {
      "title": "一覧の表示を改善",
      "what": "進捗の一覧を追加した",
      "why": "作業の進み具合を見つけやすくするため",
      "notice": ["表示順が変わる"],
      "waiting": ["表示の確認を待っている"],
      "neta": {"score": 2, "reason": "画面で変化を示せる", "channels": ["x"]},
      "event_ids": ["sample-a"]
    }
  ]
}
```

`stories` に話題を1件以上入れてください。`title` は短い名前、`what` は何をしたか、`why` はなぜしたかを書きます。`notice` には人が知っておくべきこと、`waiting` には人を待っていることを入れます。該当するものがなければ空の配列にします。`event_ids` には、その話題の元にした入力の出来事のIDを1件以上入れてください。同じIDを繰り返さず、1つの出来事は1つの話題にだけ入れてください。

## ネタポイント

`neta.score` は、変化の大きさ、読者への価値、見せやすさを合わせて判断し、0（発信には向かない）から3（そのまま発信の芽になる）までの整数で付けてください。`reason` に点の理由を書き、`channels` には向いている場を `x`、`note`、`reddit` から選んで入れてください。

## 守ること

出来事にない事実を足さず、[伏せた] の中身を推し量らないでください。応答は日本語で書き、JSONだけを返してください。

## 頼み直し

入力に `previous_errors` があれば、その一覧の誤りを直した応答を返してください。
